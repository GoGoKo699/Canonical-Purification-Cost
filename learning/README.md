# Learning canonical purification cost

The central question is operational: what does it cost to rebuild a specified purification after its environment has been discarded? The source rank is only two, and both a mixed state and its conjugate are available. Understanding the result requires connecting that physical access model to the coherent output, then connecting symmetric tensors to the dimension-dependent cost.

The educational anchor is **John Watrous, *The Theory of Quantum Information* (Cambridge University Press, 2018)**. The [source bridge](anchor.md) identifies the relevant sections, translates the book's notation and fidelity convention, and supplies a concrete example. It also distinguishes textbook foundations from the harmonic analysis and preparation mechanism developed in this project. The author provides a [manuscript for personal reading](https://jhwatrous.github.io/books-and-courses.html); the bridge links the source directly.
