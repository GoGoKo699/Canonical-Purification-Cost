# Learning canonical purification cost

The central question is operational: what does it cost to rebuild a specified purification after its environment has been discarded? The source rank is only two, and both a mixed state and its conjugate are available. The exact frontier asks for optimal heralded success under separate hard source caps. A complementary robust theorem asks for total copy cost when a fixed approximate fidelity is sufficient. Understanding both requires connecting the access model to the coherent output and symmetric-tensor constraints.

The educational anchor is **John Watrous, *The Theory of Quantum Information* (Cambridge University Press, 2018)**. The [source bridge](anchor.md) identifies the relevant sections, translates the book's notation and fidelity convention, and supplies a concrete example. It also distinguishes textbook foundations from the task-specific polynomial rigidity, harmonic optimization, preparation mechanism and fully counted mixed-source extraction. The author provides a [manuscript for personal reading](https://jhwatrous.github.io/books-and-courses.html); the bridge links the source directly.
